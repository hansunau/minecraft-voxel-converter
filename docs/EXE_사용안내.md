# 마인크래프트 복셀 변환기 — 친구에게 보내는 안내

Windows용 프로그램입니다. `VoxelConverter.exe`를 실행하세요. 프로그램 자체와 Blender 애드온 설치는 필요 없지만, 변환 엔진으로 Blender가 필요하므로 친구의 Windows PC에 무료 Blender를 먼저 설치해야 합니다. Python은 설치할 필요가 없습니다.

Blender 공식 다운로드: https://www.blender.org/download/  (이 프로그램은 Blender 5.2.3에서 시험했습니다.)

1. EXE를 실행합니다. Blender를 자동으로 못 찾으면 첫 줄의 찾기를 눌러 설치 폴더의 `blender.exe`를 선택합니다.
2. `.blend`, `.glb`, `.gltf`, `.obj`, `.stl`, `.ply`, `.fbx` 파일을 선택하면 메시 목록을 불러옵니다. 원하는 오브젝트를 선택합니다. 하나의 메시만 변환합니다.
3. 블록 높이, 속 채우기 또는 껍데기와 두께, **블록 직접 선택**을 눌러 블록을 하나씩 선택합니다. 검색, 기본 목록, 전체 후보, 전부 해제 및 검색 결과 일괄 선택을 사용할 수 있습니다. 적용을 눌러야 변경 사항이 반영됩니다. 한국어 색상·일부 재료 이름 또는 영문 블록 ID로 검색할 수 있습니다. 단순한 닫힌 메시에서 작은 높이로 먼저 시험하세요.
4. Litematica 또는 WorldEdit을 고르고 변환하고 저장하기를 누릅니다. 출력 파일을 Minecraft의 해당 프로그램으로 가져오세요. 진행 중 취소 버튼으로 중단할 수 있습니다.

대상은 Minecraft Java 26.3 (데이터 버전 5023), Litematica 형식 v7 또는 Sponge 형식 v3입니다. 기존 원본 모델 파일은 덮어쓰지 않습니다. 외부 텍스처와 OBJ의 MTL, glTF의 BIN 파일 등은 모델과 함께 상대 경로를 유지해야 합니다. Blender는 별도 백그라운드 프로세스로 실행되며 파일을 인터넷에 올리지 않습니다.

실제 게임에서의 가져오기는 아직 시험하지 않았습니다. 창에서 3D 미리보기를 표시하지 않으며, 애드온에서 지원하던 Blender 내 미리보기는 별도 애드온 버전을 이용해야 합니다. 색상은 단순 표면 색 또는 직접 연결된 이미지 텍스처를 사용한 근사치입니다. 얇거나 열려 있는 메시는 일부가 빠질 수 있습니다. 최대 250,000 격자이며 큰 모델은 시간이 오래 걸릴 수 있습니다. 모델이 여러 오브젝트로 나뉜 경우 Blender에서 복사본을 합쳐 저장한 뒤 사용하세요. Blender 설치 버전에서 해당 형식 가져오기를 지원해야 합니다.

이 EXE는 서명되지 않아 Windows의 보안 확인 화면이 나타날 수 있습니다. 출처를 확인한 파일만 실행하세요. 친구에게 EXE와 이 설명서를 함께 보내면 됩니다. `소스` 폴더에는 프로그램과 Blender 연동 코드가 들어 있습니다.

재료는 Minecraft 26.3의 단순 불투명 큐브 후보 259종이며 건축용 기본은 자동으로 위험 가능성이 높은 재료를 제외한 186종입니다. 모든 Minecraft 블록을 지원하는 것은 아니며, 전체 후보에는 물리 작용이 있는 재료가 포함될 수 있습니다. 블록 목록은 `블록_후보목록.txt`를 참고하세요.
