# 대용량 변환과 배치

대용량 변환은 **속 채우기**만 지원합니다. EXE에서는 `대용량 구역별 저장`을 선택하고, Blender 애드온에서는 `구역별 대용량 내보내기`를 선택합니다. 높이는 최대 2,048블록이며 경계 상자 격자가 1억 5천만 개를 넘으면 중단합니다. 32×128×32 이하 구역을 순차 저장하고 빈 구역은 생략합니다.

Litematica 조각에는 전체 모델 기준 상대 위치가 포함됩니다. 모든 파일을 불러온 뒤 배치 원점을 같은 좌표로 지정해야 합니다. `manifest.json`에 상대 위치와 크기가 기록됩니다. Sponge 파일에는 Offset이 포함되지만 WorldEdit 버전별 해석은 확인이 필요합니다. 실제 게임과 서버에서 불러오기는 검증하지 않았습니다.

기본 Minecraft 오버월드의 높이는 Y=-64~319, 총 384블록입니다. 이보다 큰 구조물은 구역별로 나누더라도 기본 월드에 세로로 전체를 놓을 수 없습니다.

실행 중 Esc(애드온) 또는 작업 취소(EXE)로 중지할 수 있습니다. 취소 시 부분 파일은 남고 manifest 상태는 `incomplete`이므로 완성된 결과로 사용하지 마세요. 구역당 수백 MB와 Blender·텍스처 메모리가 필요할 수 있으며 실제 사용량은 모델에 따라 다릅니다.

모든 구역은 같은 전역 격자를 사용합니다. 색상의 경계 차이를 피하기 위해 대용량 모드에서는 이웃 색 정리를 적용하지 않습니다. 열린 메시나 겹친 면은 내부 판정이 잘못되어 줄이나 빈틈이 생길 수 있습니다. 작은 상자를 두 형식으로 분할해 모든 블록과 좌표를 비교했습니다.
